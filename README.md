# 🧼 Data Cleaning & Reporting Automation Pipeline

A cloud-deployed data operations application that automatically ingests unstructured, messy sales logs, executes programmatic audit operations via **Pandas**, and generates dynamic summaries along with exportable, standardized data streams.

## 📊 Project Objectives & Deliverables
* **Programmatic Data Auditing:** Automatically isolates and drops redundant records, standardizes text fields, fills missing entry sequences, and resolves value anomalies using programmatic statistical methods.
* **Aggregated Performance Metrics:** Computes multi-level field lookups in real time to deliver structured, high-level business insights instantly.
* **Instant Export Capability:** Packages audited, production-ready dataset results into a downloadable `.csv` buffer format through automated sidebar action features.

## 🛠️ System Frameworks Used
* **Data Processing Core:** Python 3, Pandas, Core IO Stream Utilities
* **Web UI Framework:** Streamlit Cloud Architecture

## 🚀 Repository Blueprint
* `automation_app.py` - Core application script containing processing functions, cleaning methods, and UI dashboard visual components.
* `messy_sales_data.csv` - Test pipeline log dataset filled with missing values and duplicates to demonstrate programmatic fixes.
* `requirements.txt` - Configuration blueprint specifying environmental requirements for cloud server deployment.
